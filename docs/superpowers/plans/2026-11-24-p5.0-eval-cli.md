# P5.0 Phase 5 Split Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Phase 5's single row becomes a stack of cycles whose shared calls are
settled once, so P5.1 can build the eval CLI's resolution and records without
re-arguing what belongs in it.

**Architecture:** One phase-5 spec that cites `docs/domain.md` instead of
restating it, the roadmap rows, a changelog line, and one pull request. No runtime
code, no package publish, no process started.

**Tech Stack:** The existing gates: `npm test` (`doc-caps`, `doc-lifecycle`,
`docs-links`), `npm run check:docs`, `uv run pytest`.

**Spec:** `docs/superpowers/specs/2026-11-24-p5.0-eval-cli-design.md`

## Global Constraints

- Branch `p5.0/phase-5-cycles`, cut from `origin/main`, independent of the phase-4
  stack: it touches the roadmap, the changelog and two new documents, and nothing
  the stacked cycles touch, so the two can merge in either order.
- P5.1 branches from this branch; P5.2 from P5.1. One pull request each.
- No `src/` change, no `pyproject.toml` entry point, no test added: P5.1 owns those.
- The spec stays within 150 lines with a brief of at most 30, and every decision
  keeps its attribution.
- `docs/domain.md` is cited, never restated — it already fixes the record tree,
  the resolution order and the statuses.

## Review Focus

- **A spec that duplicates the domain document.** The two would drift, and the
  domain document is the map. Pinned by the spec's opening link and by its
  non-goals naming what belongs there.
- **A split that leaves P5.1 undemonstrable.** Resolution and records can be proven
  with fixtures; spawning Pi cannot, in a suite that forbids processes. Pinned by
  the P5.1 row excluding every child process.
- **A Pi version gate that flatters.** The gate checks the declared peer range,
  not the targeted version, and the spec records that this machine sits at the
  floor of that range.
- **A merge that collides with the phase-4 stack.** Different files, so the order
  does not matter. Pinned by reviewing both diffs together.
