# P2.2 Rules Index and Mapped Records Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new contributor's agent finds the effective rules from a root `AGENTS.md`, with honest records for deferred work and observed failures.

**Architecture:** A short always-loaded index (`AGENTS.md`) plus a routing skill, two empty evidence records, and dated mappings in `docs/rules-applicability.md`. Documentation only; no runtime code, no new test dependency.

**Tech Stack:** Markdown; Pi project skills under `.agents/skills/`; existing `npm test` / `uv run pytest`.

**Spec:** `docs/superpowers/specs/2026-11-18-p2.2-rules-index-design.md`

## Global Constraints

- Branch `p2.2/rules-index`, stacked on `p2.1/contributor-setup`; one PR into that branch.
- `docs/sdd.md` and `docs/provenance/mellum-worker-AGENTS.md` stay byte-for-byte; never edited.
- `AGENTS.md` ≤ 80 lines; states spec 150 / plan 250 / reviewer brief 30 as budgets that tighten the preserved 400-line caps for new work.
- Links only to destinations that exist after this cycle; the P2.3 cap check is named, not linked.
- `BACKLOG.md` and `docs/pathologies.md` ship with formats and zero entries; no invented deferred work or failures.
- Glossary stays product vocabulary; process terms are defined where used.
- Default suites stay model-, network- and subprocess-free.
- Stale references in `README.md`, `docs/domain.md` and `CHANGELOG.md` are corrected; P2.1 content is not rewritten.

## Review Focus

- **Dangling links** in `AGENTS.md` or the records: every target must exist now. Checked in Task 4's link pass.
- **`AGENTS.md` over 80 lines or re-copying rules**: the index must point, not restate. Checked in Task 1 and Task 4.
- **Wrapper skill collision or invalid frontmatter**: name `satyrn-pi`, valid `SKILL.md`, no duplicate. Checked in Task 1.
- **Preserved files touched**: `docs/sdd.md` and `docs/provenance/` must be absent from the branch diff. Checked in Task 3 and Task 4.
- **Empty records read as unfinished**: both files must say plainly that zero entries is valid. Checked in Task 2.
