# P2.6 Discovery Demonstration and Phase Close Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A fresh agent finds the effective rules unaided, and Phase 2 closes with every active path resolved, both suites run, and statuses that match the unmerged stack.

**Architecture:** A committed link test over root Markdown and `docs/**`, a read-only fresh-subagent demonstration in a temporary clone, and a recorded close checklist. No runtime code.

**Tech Stack:** Node >= 20 (`node:test`, `node:fs`), existing suites, the `worker` subagent.

**Spec:** `docs/superpowers/specs/2026-11-18-p2.6-demonstration-close-design.md`

## Global Constraints

- Branch `p2.6/demonstration-close`, stacked on `p2.5/tripwire-import`.
- Link scope: root `*.md` plus `docs/**/*.md`; exclude `docs/sdd.md`, `docs/provenance/**`, `docs/superpowers/plans/archive/**`, `.superpowers/**`.
- Default suites stay model-, network- and subprocess-free; the link check reads files only.
- The demonstration is read-only, in a scratch clone of the branch tip, with no pointers in the prompt and the model recorded.
- P2.6 stays in flight; `## Now` says Phase 2 is complete pending review of #7–#12; no row claims a merge.
- Preserved files stay byte-for-byte.

## Review Focus

- **A hollow demonstration**: Pi may auto-load `AGENTS.md`, so acceptance requires the budgets, current row, cycle and checks beyond it; the record says what was auto-loaded. Pinned by the demonstration record.
- **A link check that includes preserved or archived files**: scope excludes them, so the known `docs/sdd.md` source link does not need a broken-link allowlist. Pinned by the scope test.
- **A close claim that asserts merges**: statuses stay in flight and `## Now` names the open PRs. Pinned by reviewing the roadmap diff.
- **A preserved check that cannot run**: the source recipe and the stack diff are both recorded, with the source half marked unverified if the checkout is absent. Pinned by the close evidence.
- **A demonstration miss hidden by a rerun**: one fix and one confirmation run, then a reviewed negative. Pinned by the recorded run count.
