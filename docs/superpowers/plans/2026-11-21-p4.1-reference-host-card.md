# P4.1 Reference Host Card Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The reference configuration exists as a repository record — build,
weights, settings and command, each with the metadata it came from — so P4.2 can
reproduce it and Nicola can check the pin before anyone spends the download.

**Architecture:** One research note under `docs/superpowers/research/`, which the
site excludes. Two fetch commands reproduce every digest. No artifact is
downloaded and no server starts.

**Tech Stack:** `curl`, `jq`, the document gates: `npm test` (`docs-links`,
`published-pages`, `doc-wording`), `npm run check:docs`, `uv run pytest`.

**Spec:** `docs/superpowers/specs/2026-11-21-p4.0-getting-started-design.md`

## Global Constraints

- Branch `p4.1/reference-host-card`, stacked on `p4.0/phase-4-cycles`; one pull
  request based on that branch, retargeted to `main` when it merges.
- The card lives at `docs/superpowers/research/2026-11-21-reference-host-card.md`.
  `exclude_docs` already covers `superpowers/`, so nothing under it can become a
  published page and `zensical.toml` is untouched.
- Every value is quoted from a publisher response or from the source at
  `0e4a9b68`, with the file it came from named. No value is transcribed by hand.
- This cycle fetches metadata only: no 8.1 GB download, no `llama-server`, no
  measurement. Everything that would need a running server belongs to P4.2.
- Preserved paths stay byte-for-byte; the host card is a new document.

## Review Focus

- **A selector passed off as a pin.** `Q4_K_M` names a quantisation and `b12066`
  names a release; neither survives a replacement at the head. Pinned by the
  revision, source commit and two digests in the card's tables.
- **A card that reads as if something ran.** Its first section separates what was
  fetched from what is conjecture, and P4.2 is named as the cycle that proves it.
- **Divergence from the preserved command hidden.** The card shows the source's
  own argv beside the documented one and states the single change — `-hf` to
  `-m` — with the rig note's reason. Pinned by the two fenced commands.
- **A record published by accident.** The card sits under `superpowers/`, so the
  published set is still two pages. Pinned by `published-pages`.

**Files:** none — the commands are evidence.
