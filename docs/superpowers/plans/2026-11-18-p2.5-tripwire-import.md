# P2.5 Default-Test Tripwire and Import Direction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Default tests cannot acquire a process or network dependency unnoticed, and the worker and eval packages cannot import each other.

**Architecture:** One JSON rule table, a JS guard test in `npm test`, a Python guard test in `pytest`, and an import-direction checker test. Fixtures live in temp dirs or are assembled from parts; repository scans read files only.

**Tech Stack:** Node >= 20 (`node:test`, `node:fs`), Python 3 standard library (`json`, `ast`, `pathlib`), existing `npm test` and `uv run pytest`.

**Spec:** `docs/superpowers/specs/2026-11-18-p2.5-tripwire-import-design.md`

## Global Constraints

- Branch `p2.5/tripwire-import`, stacked on `p2.4/vocabulary`; one PR into that branch.
- Tripwire scans `tests/**/*.mjs` and `tests/**/*.py` only; no transitive analysis.
- One rule table, `scripts/default-test-rules.json`, read by both guards.
- Strip `//` and `#` line comments; match import syntax and named calls, not bare words.
- Import check walks the repo minus `node_modules`, `.venv`, `.git`, `.superpowers`, `docs`, `tests`, `scripts`.
- Default suites stay model-, network- and subprocess-free; preserved files unchanged.
- Fixtures never carry a full forbidden pattern in the guard's own source; assemble them from parts.

## Review Focus

- **The guard flagging itself**: fixtures are built from parts and comments are stripped. Pinned by the repository scan passing with the guard test present.
- **Comment and prose false positives**: a comment naming a forbidden import or `os.system()` passes. Pinned by the comment fixture.
- **A vacuous import walk**: today no JS/TS exists outside `tests/` and `scripts/`, so a temp-dir fixture proves the walker finds a real file. Pinned by the positive-control test.
- **JS and Python rule drift**: both read the same JSON file. Pinned by the Python guard reading the same table.
- **Obvious evasions**: `globalThis.fetch(`, `from os import system`, and `require("node:child_process")` are caught. Pinned by fixtures.
