# P6.1 Suite Data and Provenance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The three preserved suites live in the Python package exactly as they were
pinned, their provenance is machine-checkable, and the loader refuses a suite whose
copy or expectations disagree with it.

**Architecture:** `src/satyrn_pi/suites/suite-<name>/source/` holds the 95 copied
files; `SOURCES.json` beside it records `copied`, `reference` and `authored`, so the 24
source graders are named with hashes and no local file; an authored `suite.json` points
one task at `source/` with the suite's prompts joined into one instruction. A new
`src/satyrn_pi/suites.py` validates the data and `resolve_suite` calls it, so a bad
suite fails before a job directory exists.

**Tech Stack:** Python 3.12 dataclasses and `hashlib`; `pathlib`; pytest; `git archive`
and `tar` for the copy; the Node checks unchanged.

**Spec:** `docs/superpowers/specs/2026-11-26-p6.0-suites-and-grading-design.md` ·
[the environment note](../research/2026-11-26-grading-environment.md)

## Global Constraints

- Source `andrevanzuydam/mellum-worker`, commit
  `0e4a9b6859cbe447adbca537c5738f24a862d214`. Every copied byte comes from it: nothing
  is re-typed, re-wrapped, reordered or de-duplicated.
- 95 copied files, 867,403 bytes. 24 `reference` files, 36,632 bytes, 13 test modules,
  named relative to the source suite directory, requiring no local file.
- `expected.json` IDs: Easy 4, Medium 18, Hard 34, all prefixed `grader_tests/`.
- The instruction is `prompts/*.md` sorted, each `.strip()`ed, joined with `"\n\n"`;
  `promptMode` is `joined`; `version` is `"1"`; the weight budget becomes 320 files and
  2.5 MB.
- No default test starts a process, opens a socket or reaches the network. The tripwires
  scan `tests/python/**/*.py` and `tests/**/*.mjs`, so `src/` copies stay outside their
  reach. `uv_build` already ships `src/satyrn_pi/suites/**`; add no build configuration.

## Review Focus

- **A normalised file.** Every read of the copy is binary; a text read corrupts Hard's
  three `data.db` fixtures and any hash taken over one.
- **A nested `.gitignore`.** The fixtures bring their own, so `git status --porcelain`
  must be clean after each commit or a copied file was silently skipped.
- **A re-wrapped `instructions`.** The join test recomputes it from `source/prompts/`.
- **The five P5 fixture suites**, which have no `source/` and must keep loading.
- **A suite that loads without graders.** `graders is None` must be visible to P6.2,
  not silently treated as "nothing to check".

### Task 1: The copied suites, the manifest, and the weight budget

**Files:** `src/satyrn_pi/suites/suite-{easy,medium,hard}/source/**` (95 files) and
`SOURCES.json` in each; `tests/python/test_suites.py`; `scripts/repo-weight.mjs`.

**Interfaces:** produces `SOURCES.json` with `repository`, `commit`, `hash` (`"sha256"`),
`copied` (relative to `source/`, hex digest), `reference` (relative to the source suite
directory, hex digest, no local file) and `authored` (local paths the port owns).

- [x] **Step 1: Write the failing manifest test.** In `tests/python/test_suites.py`:

```python
import hashlib, json
from pathlib import Path

SUITES = Path(__file__).resolve().parents[2] / "src" / "satyrn_pi" / "suites"
NAMES = ("easy", "medium", "hard")

def test_the_manifest_matches_the_copied_tree():
    for name in NAMES:
        root, source = SUITES / f"suite-{name}", SUITES / f"suite-{name}" / "source"
        copied = json.loads((root / "SOURCES.json").read_text())["copied"]
        on_disk = {str(p.relative_to(source)) for p in source.rglob("*") if p.is_file()}
        assert set(copied) == on_disk, name
        for relative, digest in copied.items():
            assert hashlib.sha256((source / relative).read_bytes()).hexdigest() == digest
```

- [x] **Step 2: Verify it fails.** `uv run pytest tests/python/test_suites.py -q` —
  expect `FileNotFoundError` for `suite-easy/SOURCES.json`.

- [x] **Step 3: Copy the 95 files.** From the repository root:

```sh
SRC=~/projects/satyrn/mellum-source
for suite in easy medium hard; do
  dest="src/satyrn_pi/suites/suite-$suite/source"; mkdir -p "$dest"
  git -C "$SRC" archive 0e4a9b68 "learn/code/suites/$suite" | tar -x -C "$dest" --strip-components=4
  rm -rf "$dest/grader"          # re-earned, not copied
```

The `grader/` tree is extracted and deleted rather than excluded, because an exclude
pattern must match the archive's own path. Expect
`find src/satyrn_pi/suites -path '*/source/*' -type f | wc -l` to print `95`, and no
`source/grader` directory anywhere.

- [x] **Step 4: Generate `SOURCES.json`** from the copy and the pinned commit — never
  by hand, and never over a text read:

```sh
python3 - <<'GEN'
import hashlib, json, pathlib, subprocess
ROOT, SRC = pathlib.Path("src/satyrn_pi/suites"), pathlib.Path.home() / "projects/satyrn/mellum-source"
COMMIT = "0e4a9b6859cbe447adbca537c5738f24a862d214"
git = lambda *a: subprocess.run(["git", "-C", str(SRC), *a], capture_output=True, check=True).stdout
for name in ("easy", "medium", "hard"):
    root = ROOT / f"suite-{name}"
    source = root / "source"
    copied = {str(p.relative_to(source)): hashlib.sha256(p.read_bytes()).hexdigest()
              for p in sorted(source.rglob("*")) if p.is_file()}
    paths = [p for p in git("ls-tree", "-r", "--name-only", COMMIT,
             f"learn/code/suites/{name}/grader").decode().split("\n") if p]
    reference = {p.split(f"/{name}/", 1)[1]:
                 hashlib.sha256(git("show", f"{COMMIT}:{p}")).hexdigest() for p in paths}
    (root / "SOURCES.json").write_text(json.dumps({
        "repository": "andrevanzuydam/mellum-worker", "commit": COMMIT, "hash": "sha256",
        "copied": copied, "reference": reference, "authored": ["suite.json"]},
        indent=2, sort_keys=True) + "\n")
GEN
```

## Refinements this plan makes to the spec

- **The grader-module refusal is conditional on `graders/` existing.** P6.1 ships none —
  P6.2–P6.4 re-earn them — so an unconditional rule would refuse every suite here. P6.2's
  `grade` refuses `graders is None`, so it cannot be silently off where it matters.
- **The file-set check is scoped to `source/`**, both directions: `reference` and
  `authored` are provenance facts, not members, which is also why the P5 fixtures need no
  manifest.
