# P2.4 Vocabulary Budget and Retired-Term Check Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The 25-term glossary budget and the retired product names are enforced by model-free checks in the default suite.

**Architecture:** A data module for retired terms and scope, a pure checker module, a glossary-budget constant beside the P2.3 budgets, and CLI wiring. Fixtures are in-memory strings; repository scans read files only.

**Tech Stack:** Node >= 20 (`node:test`, `node:fs`, `node:path`), existing `npm run check:docs`.

**Spec:** `docs/superpowers/specs/2026-11-18-p2.4-vocabulary-gates-design.md`

## Global Constraints

- Branch `p2.4/vocabulary`, stacked on `p2.3/gates`; one PR into that branch.
- Scope: `README.md`, `AGENTS.md`, `BACKLOG.md`, and `docs/**/*.md`; exclude `docs/sdd.md`, `docs/rules-applicability.md`, `docs/superpowers/**`, `docs/provenance/**`, root `BRIEF.md` and `ROADMAP.md`.
- Retired terms: `stage`, `floor`, `remedy unit`, `tier`, `ladder`, `rung`; plurals match, `staging` does not; fenced blocks are skipped.
- Exemptions: `<!-- vocabulary: <non-empty reason> -->` on the same or preceding line; headings never exempt.
- Glossary budget: 25 `###` entries; aliases do not count.
- Default suites stay model-, network- and subprocess-free; preserved files stay byte-for-byte.
- Rewords in `docs/domain.md`: `Stage` → `Step`, “grading stage” → “grading step”, “checkout-local ladder” → “checkout-local source tree”.

## Review Focus

- **A fenced block tripping the check**: fences are skipped, including shell comments starting with `#`. Pinned by the fenced-block fixture.
- **`staging` or `stages`**: plurals fail, longer words pass. Pinned by both fixtures.
- **Scope creep into process records**: `BRIEF.md`, `ROADMAP.md`, `docs/sdd.md`, `docs/rules-applicability.md`, plans/specs/research/provenance are not collected. Pinned by the scope test.
- **An empty exemption reason**: `<!-- vocabulary: -->` does not exempt. Pinned by the empty-reason fixture.
- **Aliases counted as terms**: only `^### ` headings count toward 25, not `<!-- zensical-glossary-aliases: -->`. Pinned by the budget fixture with aliases.
