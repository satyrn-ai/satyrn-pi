# P2.5 default-test tripwire and one-way import check: design

## Reviewer brief

**Intent:** the default test suites cannot acquire a process, network or model
dependency unnoticed, and the worker and eval packages cannot import each other.

**Decisions:** the tripwire scans the two test trees only — `tests/**/*.mjs` and
`tests/**/*.py` — not their transitive imports; one JSON rule table feeds a JS
guard in `npm test` and a Python guard in `pytest`; the scanner strips line
comments and matches import syntax, not bare words; the import check walks JS/TS
outside `tests/` and `scripts/` and Python under `src/satyrn_pi/`. Each is proven
by a planted violation.

**Non-goals:** CI wiring, runtime interception, transitive import analysis, the
discovery demonstration (P2.6), runtime code, or a model/network/subprocess
change to the suites.

**Verification:** fixtures prove permitted and refused cases in both directions;
the real trees pass; one planted test import fails `npm test`, then is removed.

## Intent and why

`BRIEF.md:196-201` requires default tests with no model, network or subprocess,
and a one-way import check. The source never enforced either: its default suite
spawns `uv`, `git` and `bash`, and it has no tripwire or import test.

A planted process-spawning test that fails the build is the proof the tripwire
works; a matching success case keeps an unrelated failure from satisfying it
(`BRIEF.md` binding rule 4).

## Goals

- `scripts/default-test-guard.mjs`: a pure scanner for forbidden imports and
  calls, plus a collector for the two test trees.
- `scripts/default-test-rules.json`: one forbidden-module table read by both
  guards.
- `scripts/import-direction.mjs`: the mechanical one-way import check between the
  npm worker side and the Python eval package.
- `tests/python/test_default_guard.py`: the Python tripwire, so `pytest` alone
  also refuses a process or network import.
- Tests for both, with permitted and refused fixtures in temporary directories.
- One planted test import, seen failing `npm test`, then removed.
- `AGENTS.md` names the tripwire and the import check in its checks section;
  the roadmap row and `## Now` are updated.

## Non-goals

- CI configuration, GitHub Actions or a pre-commit hook.
- Runtime interception of `spawn`/`fetch`; this is a static scan.
- Transitive analysis of modules imported by tests. `tests/setup.test.mjs`
  imports `scripts/setup.mjs`, which imports `node:child_process`; that stays
  valid because the test never executes the real `exec`.
- Scanning `scripts/` as if it were a test, or forbidding `node:fs`/`node:path`.
- The discovery demonstration and phase close (P2.6).
- Any runtime code or change to the existing suites' behavior.

## Anti-goals

- A scanner that flags its own fixtures, terms in prose, or ordinary comments.
- A check that spawns a process to test process-spawning.
- A blanket ban that makes `scripts/setup.mjs` or its tests fail.
- A refusal test without a sibling success test.

## Constraints

- Branch `p2.5/tripwire-import`, stacked on `p2.4/vocabulary`; one PR into that
  branch.
- Default suites stay model-, network- and subprocess-free; the checks read files
  only.
- Preserved files stay byte-for-byte; the current 60 Node and 2 Python tests
  keep passing.
- Fixtures live outside the repository in temporary directories, so repository
  scans never see them.

## Decisions

- **Scan the test trees only.** `tests/**/*.mjs` and `tests/**/*.py`. A test that
  imports a local module with process capability is out of scope until a later
  cycle chooses transitive analysis; the spec says so. (Paul's decision.)
- **One rule table, two guards.** `scripts/default-test-rules.json` lists the
  forbidden modules and calls; the JS guard reads it and the Python test reads
  the same file, so the suites cannot drift. (Assistant.)
- **Match syntax, not bare words.** Strip JS comments string-aware (so a URL or a
  quoted `#` cannot hide a call); parse Python with `ast`, including aliases and
  `from os import system as run`. Match side-effect imports, `from`/`require`/
  dynamic-`import` specifiers, `fetch(` (with optional `globalThis.`, not
  `client.fetch`), and `os.system`/`os.popen`. Fixtures are assembled from parts
  so the guard's own test never contains a full forbidden pattern. (Assistant.)
- **Repo-wide import walk with a fixture control.** The import check walks the
  repository, excluding `node_modules`, `.venv`, `.git`, `.superpowers`, `docs`,
  `tests` and `scripts`; today that set is empty, so its real-tree pass is
  vacuous and temp-dir fixtures prove the walker finds files. (Assistant.)
- **Correct the attribution.** `docs/domain.md` is updated from “P2.1's one-way
  import check” to “P2.5's one-way import check”. (Assistant.)
- **Subprocess and network both.** JS forbids `child_process`, `net`, `http`,
  `https`, `http2`, `dgram`, `tls` (with or without the `node:` prefix) and bare
  `fetch(` (also `globalThis.fetch(`). Python forbids `subprocess`, `socket`,
  `urllib`, `http`, `requests`, `httpx`, `aiohttp`, `os.system`/`os.popen`, and
  `from os import system|popen`. (Assistant, from BRIEF.)
- **Parse specifiers, not raw words.** The JS scanner extracts `from`,
  `require(` and dynamic `import(` specifiers and matches bare `fetch(`; the
  Python scanner reads import statements and the two `os` calls. Fixtures are
  files in temp dirs, so the scanner never flags its own test. (Assistant.)
- **Import direction is textual.** JS/TS outside `tests/` and `scripts/` must not
  import `satyrn_pi`, a `.py` path, or anything under `src/satyrn_pi/`. Python
  under `src/satyrn_pi/` must not import `remedies`, `extensions`, `worker` or a
  `.js`/`.ts`/`.mjs` path. Missing directories are skipped. (Assistant, from
  `docs/domain.md`.)
- **Both checks run as tests.** They are discovered by `npm test`; no new npm
  script is needed. (Assistant.)
- **Planted proof, not a commit.** A new test file imports `node:child_process`,
  the tripwire suite is seen failing, and the file is deleted. (Assistant.)
- **The check reports.** It returns findings with path and line; nothing is
  edited. (Assistant.)

## Check definitions

- **Tripwire (JS):** for each `tests/**/*.mjs`, strip comments, extract specifiers
  (including side-effect imports) and flag a forbidden module, then flag
  `fetch(`. **Tripwire (Python):** for each `tests/python/**/*.py`, parse with
  `ast` and flag a forbidden import (including aliases) or `os.system`/`os.popen`
  call. Both read `default-test-rules.json`.
- **Import direction:** for each `.js/.mjs/.ts` outside `tests/` and `scripts/`,
  flag a specifier naming `satyrn_pi`, ending `.py`, or containing
  `src/satyrn_pi`; for each `.py` under `src/satyrn_pi/`, flag an imported root
  named `remedies`, `extensions` or `worker`, or a specifier ending
  `.js`/`.ts`/`.mjs`.
- **Findings:** `{ path, line, rule, message }`; line is 1-based where available.

## Left to the builder

- Exact module and function names, the forbidden lists' spelling, and the finding
  text.
- Whether the tripwire and import checks share a specifier parser.
- The collector's traversal and exclusion details.
- How the planted violation and the AGENTS/README wording are recorded.

## Verification

- `npm test` passes with the new tests; `uv run pytest` passes; `check:docs`
  reports no findings; `git diff --check` clean.
- Fixtures prove: a forbidden JS import fails; `fetch(` fails; `node:fs` passes;
  a forbidden Python import fails; stdlib `json` passes; a JS import of
  `satyrn_pi` fails; a Python import of `remedies` fails; a permitted direction
  passes.
- One planted `tests/planted-spawn.test.mjs` fails `npm test` and is deleted;
  the Python guard is shown failing on a fixture in pytest.
- `docs/domain.md` names P2.5, not P2.1, for the import check.
- Preserved files and the existing test suites are unchanged.
