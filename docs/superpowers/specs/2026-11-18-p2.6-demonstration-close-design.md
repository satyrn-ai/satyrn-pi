# P2.6 discovery demonstration and phase close: design

## Reviewer brief

**Intent:** a fresh agent can find the effective rules unaided, and Phase 2
closes with every active path resolved and both default suites run.

**Decisions:** the demonstration is a read-only fresh subagent given one minimal
prompt in a temporary clone; a committed link test covers root Markdown and
`docs/**`, excluding the preserved `docs/sdd.md`, provenance and archives;
close rows stay in flight until the stack merges, and `## Now` says Phase 2 is
complete pending review.

**Non-goals:** merging, optimistic closure, a product feature invented to prove
process, runtime code, or changes to the P2.1–P2.5 deliverables beyond a link
fix a failed demonstration proves necessary.

**Verification:** the subagent names `AGENTS.md`, the budgets, the roadmap row
and the checks without hints; the link test passes on the real tree; both
suites pass; preserved files are byte-identical.

## Intent and why

P2.1–P2.5 installed the rules and the gates. P2.6 answers the phase's real
question: can a new contributor's agent find them? It also performs the phase
close: every active path resolves, both suites run, and the record says honestly
what is merged and what is still in review.

## Goals

- A fresh-agent demonstration: a temporary clone of the branch, one minimal
  prompt, no pointers; record the actions and whether it found `AGENTS.md`, the
  document budgets, the current roadmap row, the cycle sequence and the checks.
- `tests/docs-links.test.mjs` and `scripts/doc-links.mjs`: resolve relative links
  in root Markdown and `docs/**`, excluding `docs/sdd.md`, `docs/provenance/**`
  and `docs/superpowers/plans/archive/**`; fixtures plus a real-tree pass.
- A close checklist recorded in the plan: links, both suites, budgets, preserved
  byte-identity, and statuses that match reality.
- Roadmap `## Now` says Phase 2 is complete pending review of #7–#12; P2.6's row
  stays in flight until merge.

## Non-goals

- Merging the stack, approving reviews, or marking P2.1–P2.6 closed before their
  PRs land.
- Inventing a product feature to demonstrate the process.
- Runtime code, model calls, network or subprocess in the default suites.
- Rewriting P2.1–P2.5 documents; only a link fix that the demonstration proves
  is missing may be made, and it is recorded.
- A human onboarding guide; Ben owns that at P9.1.

## Anti-goals

- A demonstration that is really the author testing their own memory.
- A link check that includes preserved files or archives and then needs an
  allowlist of broken links.
- A phase-close claim that asserts merges or review outcomes that have not
  happened.
- A pass claimed from a single quiet run: the demonstration is qualitative, not a
  rate.

## Constraints

- Branch `p2.6/demonstration-close`, stacked on `p2.5/tripwire-import`.
- Default suites stay model-, network- and subprocess-free; the link check reads
  files only.
- Preserved files stay byte-for-byte; the known `docs/sdd.md` source link stays
  excluded with its mapping in `rules-applicability.md`.
- The demonstration uses a fresh subagent and a scratch clone, so the working
  tree is untouched.

## Decisions

- **Read-only, minimal-prompt demonstration.** The subagent is told only that it
  is a new contributor and asked how it would take the next roadmap cycle from
  its row to a reviewed close; it must name documents and checks. The prompt does
  not mention `AGENTS.md`, budgets, Superpowers or the roadmap row. (Paul's
  decision.)
- **The model is recorded, not chosen for capability.** A normal contributor
  model is the honest subject; the run records which model was used and the first
  actions, without claiming a rate. (Assistant.)
- **Link scope excludes preserved and archived files.** Root Markdown plus
  `docs/**`, minus `docs/sdd.md`, `docs/provenance/**` and the archive. The one
  known source link in `docs/sdd.md` is mapped, not edited. (Assistant, from the
  measured baseline.)
- **The link check is a test, not a script.** It runs in `npm test`; fixtures live
  in temp dirs; the real tree must resolve. (Assistant.)
- **Close is recorded honestly.** P2.6 stays in flight, `## Now` says Phase 2 is
  complete pending review of #7–#12, and the rows flip to closed only after the
  stack merges. (Paul's decision.)
- **A failed demonstration is a finding.** Record the miss, fix the smallest
  documentation gap, and allow exactly one confirmation run; a second miss closes
  as a reviewed negative with the gap named, not hidden. (Assistant.)
- **Run after the link test, before the close edits.** The scratch clone is the
  branch tip commit, so it contains P2.6's spec, plan and link test, while
  `## Now` still points at the cycle in flight; findings arrive before the close
  record is written. (Assistant.)
- **Harness and auto-loading are recorded honestly.** The run uses a fresh
  `worker` subagent on the session model, read-only, with no pointers. Pi may
  auto-load project `AGENTS.md`; the acceptance test therefore requires content
  beyond it — the four budgets, the current row, the cycle and the checks — and
  the record says what was auto-loaded. (Assistant.)
- **Preserved check has two readings.** Run the source recipe
  (`git -C ~/projects/pauleveritt/mellum-worker show 0e4a9b68:… | diff`) and the
  stack diff against `p2.5/tripwire-import`; if the source checkout is missing,
  record the source half as unverified. (Assistant.)
- **No invented product work.** The demonstration is a read-only report, not an
  implementation, so it proves discovery and cycle knowledge without a feature.
  (Assistant.)

## Check definitions

- **Links:** for each scoped Markdown file, extract `](target)`; ignore `http`,
  `mailto` and pure anchors; strip anchors; resolve relative to the file's
  directory; a missing target is a finding with path and target.
- **Scope:** root `*.md` plus `docs/**/*.md`, excluding `docs/sdd.md`,
  `docs/provenance/**`, `docs/superpowers/plans/archive/**` and `.superpowers/**`.
- **Close checklist:** `npm test`, `uv run pytest`, `npm run check:docs`,
  `git diff --check`, preserved diffs against `0e4a9b68`, and a `git diff --stat`
  showing no changes under preserved or archived paths.

## Left to the builder

- Exact module and test names, the link-walk implementation, and finding text.
- The demonstration prompt's final wording, provided it contains no pointers.
- How the demonstration transcript is summarised and where it is recorded.
- The exact close-checklist wording in the plan and PR.
- Whether a documentation gap found by the demonstration is fixed in this cycle.

## Verification

- The fresh subagent names `AGENTS.md`, the four budget numbers, the current
  roadmap row, the cycle sequence and `npm test`/`uv run pytest`/`check:docs`
  without being told.
- The link test fails on a fixture with a broken relative link and passes on the
  real tree; the known `docs/sdd.md` link is excluded with its reason.
- Both suites and `check:docs` pass; preserved files diff clean.
- Roadmap statuses and `## Now` match the unmerged stack; no closure is claimed.
