# Satyrn Pi

A small local model as a bounded coding worker inside [Pi](https://pi.dev).

Mellum 2.1 runs on your machine through `llama-server`. Satyrn Pi switches a Pi
session to it for one bounded task, keeps the work inside that task, and hands
your main model a report when it finishes. Your main model stays in charge.

The port is in progress. This site carries the home page and the
[glossary](glossary.md); the worker, the measurement command and the suites are
being rebuilt in the open, and the [roadmap](https://github.com/satyrn-ai/satyrn-pi/blob/main/ROADMAP.md)
says what comes next.

[Get started](getting-started.md) — run the model on your machine, in one page.

## Who it is for

Developers who want a small model doing bounded work on their own machine,
and who want to know what each part of the setup earns before trusting it.
