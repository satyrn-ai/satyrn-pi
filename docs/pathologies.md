# Observed failure shapes

This records failure shapes this project has actually observed in the worker,
with evidence. It is not a hypothesis list or an Education lesson. Add an entry
only when a cycle's evidence shows a shape that is not already here; zero
entries is valid.

## Entry format

### Shape

- **Observed in:** the cycle and date
- **What happened:** one or two lines describing the behavior
- **Evidence:** a link to the run record, research note or plan evidence
- **Status:** open, remedied, or otherwise qualified
